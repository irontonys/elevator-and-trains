# Glosario del dominio

<!-- Términos que significan algo particular AQUÍ y que Claude no puede adivinar. -->

| Término | Significa |
|---|---|
| Bloque de inicio / límite | Par de bloques custom iguales (`eleytren:...`) que marcan el rango vertical de un elevador: el de abajo es el inicio, el de arriba es el límite. |
| Piso (del elevador) | Nivel detectado por suelo real entre el bloque de inicio y el de límite, no por una altura fija. Un salto = un piso. |
